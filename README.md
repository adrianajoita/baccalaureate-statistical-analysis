# baccalaureate-statistical-analysis
Statistical analysis of Baccalaureate graduates' experiences using descriptive statistics, z-Test, and ANOVA in Microsoft Excel.
* Partnered with a teammate to collect and analyze survey data from 569 respondents across 8 regions and 8 variables (1957–2024 cohorts).
* Led hypothesis testing (z-Test, ANOVA), uncovering significant generational variance in exam stress and urban-rural parity.
* Evaluated descriptive statistics (dispersion, skewness, kurtosis) and contingency tables in Microsoft Excel to assess tutoring impact on exam grades.
* Designed charts and visual summaries to present insights and data-driven recommendations for education policy.
